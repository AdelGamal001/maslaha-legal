Account and data deletion

Updated: 2026-10-04

Currently available

The game does not require a server account.

Progress stays local; online play uses a random player identifier.

The “امسح حسابي وصوري” button does not currently delete data.

Find it under Settings, Account, then Privacy.

Remove all local data

Leave your online room and close the game first.

Fully uninstall the application to remove its local data.

Offloading while keeping application data is not enough.

For browser play, clear the game website’s stored data.

This removes local progress, settings, characters, logs, and player identifiers.

Local deletion does not erase rooms still open for other players.

Clear guide statistics only

Open “الدليل”, then “عندك سؤال؟”.

Scroll to your statistics.

Choose “امسح أرقام دليل المصلحة”, then “امسح”.

This resets guide statistics only, leaving other data unchanged.

Email deletion requests

hello@maslahagame.com

Email a request titled “Data deletion”.

Describe your request without including passwords.
