Game information

Privacy policy

Updated: 2026-09-27

Playing and your profile

The current version requires no login or password.

Your progress is stored on your device.

Online play uses a random player identifier stored locally.

Data on your device

We store your name, level, experience, and custom characters.

We store settings, inventory, missions, attendance, and achievements.

We store gameplay statistics, ongoing matches, and tutorial steps.

Local logs contain matches, virtual currency purchases, and application errors.

Error logs include shortened messages and timestamps.

These logs stay local and are not automatically transmitted.

Unlocked administrator mode also stores its access data locally.

You can manually export administrator reports for sharing or downloading.

Online rooms

The server receives your name, character, and random player identifier.

It also receives room codes and game connection version information.

It relays player positions, actions, and match state between participants.

Positions describe the game, not your physical location.

Room participants can see your name and character.

One player hosts the simulation and knows all players’ cards.

Minigame results are sent; sensor readings and audio are not.

Server code holds rooms temporarily in memory.

Server code does not store match results in a database.

The default connection uses Colyseus Cloud in Frankfurt.

Motion and microphone

Some minigames use tilt, shaking, and rotation.

The microphone measures sound levels for blowing interactions only.

Audio is never recorded, saved, or transmitted.

Motion readings are processed locally, without saving or transmission.

The game requests permission when you choose sensor controls.

Touch controls remain available if you deny permission.

Advertising and measurement

The current version has no advertisements or external analytics tools.

There are no third-party tracking tools.

The server counts rooms and messages to operate the service.

It also measures memory, processor usage, and uptime.

These measurements differ from the local gameplay logs described above.

Deletion and contact

You can remove local game data from your device.

The data deletion page explains steps and limitations.

Use the support page for questions.
